# Portrait

Place Glorious Moraa's photograph here as:

    public/images/glorious-portrait.jpg

Recommended: a square-ish crop around head and shoulders, ~900×900px, JPEG quality ~80 (under 150 KB).
The hero crops it into a circle with the focal point near the top (`object-position: 50% 18%`), so leave
a little headroom above the hair.

To change the filename or alt text, edit `src/data/profile.ts` (`portrait`, `portraitAlt`).
